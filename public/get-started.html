Step 2: Get API Keys

Estimated time: 3 minutes

Motion Studio Pro requires API keys from two services to function. Both offer free tiers to get started.

Kling AI API Keys

Kling AI powers the actual video generation. Here's how to get your credentials:

  1. Go to klingai.com
  2. Sign up for an account
  3. Navigate to API Settings
  4. Copy your Access Key and Secret Key

Supabase Credentials

Supabase provides authentication, database, and file storage:

  1. Go to supabase.com
  2. Click New Project (free tier is fine)
  3. Wait ~2 minutes for setup
  4. Go to Settings → API
  5. Copy your Project URL and anon/public key

Cost Note: Kling AI charges per generation (~$0.05-$0.20). Supabase free tier is generous for testing.

Step 3: Configure Environment

Estimated time: 1 minute

Create your environment configuration file:

# Copy the example file
cp
.env.example .env

Open .env in your editor and fill in your credentials:

# Kling AI Configuration
VITE_KLING_ACCESS_KEY=paste_your_kling_access_key
VITE_KLING_SECRET_KEY=paste_your_kling_secret_key
VITE_KLING_API_BASE_URL=/api/kling

# Supabase Configuration
VITE_SUPABASE_URL=paste_your_supabase_url
VITE_SUPABASE_ANON_KEY=paste_your_supabase_anon_key

⚠️ Security: Never commit your .env file to version control! It's already in .gitignore.

Step 4: Setup Database

Estimated time: 3 minutes

Initialize your Supabase database with the required tables and storage:

Run Database Migrations

  1. Go to your Supabase project dashboard
  2. Click SQL Editor in the sidebar
  3. Click New Query
  4. Copy the contents of supabase/migrations/20260131_initial_schema.sql
  5. Paste and click Run
  6. Create another query with supabase/migrations/20260131_create_storage_buckets.sql
  7. Click Run

Verify Setup

Check Tables:

  • Go to Table Editor
  • ✅ You should see generations and user_settings tables

Check Storage:

  • Go to Storage
  • ✅ You should see uploads and results buckets

Step 5: Run Locally

Estimated time: 1 minute

You have two options for running the app locally:

Option A: Development Mode (Recommended)

Use this for testing with the local proxy server:

# Terminal 1 - Start proxy server
node
server.js

# Terminal 2 - Start the app
npm run
dev

Update your .env:

VITE_KLING_API_BASE_URL=http://localhost:3001/api/v1

Option B: Production-Like Mode

Test how it will work in production:

npm run
dev

Make sure your .env has:

VITE_KLING_API_BASE_URL=/api/kling

🎉 Success! Open http://localhost:5173 to see your app!

Troubleshooting

"Network Error" when generating

  • Make sure the proxy server is running (node server.js)
  • Check that VITE_KLING_API_BASE_URL matches your setup
  • Verify your Kling AI credentials are correct (32 characters each)

"Authentication Error"

  • Check your Supabase URL and anon key
  • Make sure the database migrations ran successfully
  • Try signing out and back in

"Storage Error"

  • Verify the storage buckets exist in Supabase
  • Make sure both buckets are set to Public
  • Check bucket permissions in Supabase Storage settings
